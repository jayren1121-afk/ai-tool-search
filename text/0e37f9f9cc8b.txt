About task usage rates

Every step in a Zap and every external connector call uses tasks — though rates may vary. AI model tier, code runtime, and connector type each affect how many tasks an action uses.

Learn more about usage rates
Shared task pool

Tasks are shared across your account. Zap workflows, AI steps, code, MCP, and SDK all draw from the same task allocation, with no separate task budgets by product.

Scales with how you build

Simple automations stay simple to price. When you use more powerful AI models, add tools, or run longer code, usage reflects that complexity. You control the tradeoff.
