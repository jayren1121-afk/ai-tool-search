Frequently asked questions
How much does AI2SQL cost?

Start is $9 per month, Pro is $19 per month and Team is $39 per month. Billed annually, they are $7, $14 and $29 per month (save 25%). There is also a one-time Lifetime plan for $29.

Is there a free plan?

Yes. The Free plan includes 3 SQL queries a day on a demo database, and you can connect one database of your own and get 3 answers from it. Paid plans add more queries, SQL explanations and fixes; Pro and Team keep querying your own database with no answer limit.

How does the free trial work?

Every paid plan starts with a 7-day trial with full access to the plan you pick. A credit card is required to start the trial, and $0 is charged today. Cancel anytime before the trial ends and you pay nothing.

Can I cancel anytime?

Yes. Cancel from your Account page in one click. No penalties, no hidden fees.

Is my data secure?

Yes. Industry-standard encryption in transit and at rest. Database credentials are encrypted; your queries and schemas are never sold or used to train models.

Which databases are supported?

MySQL, PostgreSQL, SQL Server, Oracle, SQLite, Snowflake, BigQuery and more. AI2SQL writes SQL for all of them; Pro and Team can connect a live PostgreSQL, MySQL or SQL Server database for schema-aware generation and read-only queries.

Can I use AI2SQL inside Claude or ChatGPT?

Yes. Every plan can write SQL through the AI2SQL MCP server; Pro and Team can also run read-only queries on connected databases from Claude, ChatGPT, Cursor, VS Code and Gemini CLI, and create API keys for their own agents and n8n. Every plan can try live queries on the demo_shop sample from Claude and ChatGPT. Setup takes two minutes on the MCP page.

Do I need to know SQL to use AI2SQL?

Not at all. Describe what you need in plain English and AI2SQL generates the correct SQL for you. Perfect for beginners and non-technical team members.

Using Claude, ChatGPT or Cursor? Set up the AI2SQL MCP server.
